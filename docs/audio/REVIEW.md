## 미검증 항목과 후속 작업

- 청음하지 못했으므로 분위기·악기·보컬 유무·곡 간 개성·반복 피로도는 판정 보류.
- 디코딩하지 못했으므로 시작/끝 무음, 클릭, 음량 편차, 클리핑, 박자·화성 연결, 정확한 루프 시작/끝 시각은 판정 보류.
- 청음 환경에서 각 곡 전체와 끝 5초→시작 5초 연결을 확인하고, 후보 반복 구간을 3회 이상 들어 판정한다. 30초 길이보다 자연스러운 마디 경계를 우선한다.
- PCM WAV를 확보하면 압축 디코더 없이 파형 기반 경계·음량 분석을 진행할 수 있다. 파형 분석은 분위기 청음을 대체하지 않는다.
- 제작 경로는 최신 프로젝트 기록상 Gemini이며, 이 파일들의 구체적인 생성 모델·프롬프트·이용 조건은 별도 확인이 필요하다.
- 앱 오디오 연결 및 실제 Android 반복 재생은 이번 검수 범위에서 수행하지 않았다. `assets.json`의 음악 planned/null 상태를 유지한다.

## 실행 근거와 한계

`python scripts/inspect-music-metadata.py <원본 폴더>`로 MP4 박스 구조에서 직접 길이·오디오 샘플 항목을 읽었다. 외부 분석 패키지 설치는 네트워크 DNS 오류로 실패했다. 로컬 Chrome 분석 실행은 프로세스 시작 오류로 실패했고, 브라우저를 통한 로컬 페이지 열기는 URL 보안 정책에 거절되어 중단했다. 어떤 경로에서도 청음·파형 검수가 완료되지 않았다.
