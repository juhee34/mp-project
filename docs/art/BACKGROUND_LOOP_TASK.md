# A 담당: 배경 반복 연결 수정

2026-11-11 사용자 요청으로 남은 할 일에 추가. 상태: 예정 / 그림 수정·반복 검수 미실시.

## 목표와 범위

확정한 6명 고향의 디자인·색감·픽셀 표현·생활 소품을 유지하면서, 배경 끝에서 처음으로 돌아올 때 끊김이 덜 느껴지게 수정한다. 전체를 새 디자인으로 교체하지 않는다. A가 그림과 납품 자료를 담당하고, B는 게임에서 반복 이동을 연결하고 실제 기기에서 확인한다.

## A 작업 순서

- [ ] 현재 게임이 사용하는 6종 원본과 크기·배율·지면 기준선을 먼저 확인한다.
- [ ] 라일·치즈 → 포포·루미 → 누누·피코, 2명씩 수정·검토한다.
- [ ] 양쪽 끝의 지면 높이, 길과 벽돌 무늬, 물가·지붕·수풀 윤곽, 하늘 색과 밝기를 연결한다.
- [ ] 집·무대·선착장 같은 큰 장소와 특징적인 소품이 경계에서 잘리거나 갑자기 두 번 등장하지 않도록 주변 공간을 조정한다. 생활과 이야기 단서는 유지한다.
- [ ] 실제로 분리된 레이어가 있다면 각 레이어도 개별적으로 이어지는지 확인한다. 한 장짜리를 분리 완료라고 표시하지 않는다.
- [ ] 같은 그림 3장을 가로로 붙여 이음새를 보고, 연속 스크롤 미리보기로 경계 통과를 최소 3회 확인한다. 느린 속도와 실제 게임 속도에서 각각 확인한다.
- [ ] 수정 전후 비교, 최종 이미지, 크기·레이어 정보, 검수 결과를 함께 납품한다. 확인 전 `loopReady=true`로 바꾸지 않는다.

## 완료 기준과 B 인계

바닥이 튀지 않고 경계에 세로선·급격한 색 변화·잘린 큰 소품이 보이지 않아야 한다. 넓은 풍경에서도 반복 간격이 지나치게 눈에 띄는지 확인한다. 자연스러움에 대한 A 시각 검수와 B의 실제 게임 통합 검수를 구분해 기록한다.

B는 제공된 그림을 기존 반복 렌더링에 연결해 화면 비율·속도·레이어 배율에 따른 틈과 흔들림을 확인한다. 물리·충돌·속도 코드를 A의 배경 작업에서 수정하지 않는다. 렌더링 좌표의 틈은 그림 변경만으로 해결됐다고 보고하지 않는다.
