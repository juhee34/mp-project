# 상점 디자인 적용 기준

## 시각 방향
가방과 연결되는 크림색 천 바탕, 얇은 꿀색 나무 테두리, 짙은 초록 글자·버튼, 연보라 장식이다. 기존 붉은 극장 커튼과 물약 선반 대신 상품이 중심이 되는 차분한 배치를 사용한다. 배경 질감은 글자 읽기를 방해하지 않게 낮춘다. 픽셀 그림은 가는 갈색 외곽선과 작고 섬세한 도트로 유지한다.

아래 색상은 구현 시작용 권장값이며 원본의 정확한 픽셀 추출값은 아니다. 최종 시각 기준은 승인 PNG다.

| 카드 | #FFF9EB |
| 주요 글자·선택 | #28563B |

## 화면 구성
1. 상단: 처음으로 / 상점 / 짧은 소개 / 코인 잔액 / 가방 버튼.
2. 안내: “꾸미기는 모습만 바뀌어요. 점프와 속도는 그대로예요.”
3. 탭: 꾸미기·음악·물품·코인 충전. 선택 탭은 초록 채움, 나머지는 크림 바탕과 얇은 선.
4. 상품: 배경과 캐릭터 미리보기, 이름, 설명, 가격, 구매 상태와 버튼.
5. 하단: 작은 화분·꽃 장식. 조작 영역을 덮지 않는다.

원본은 약 16:9의 가로 화면이다. 넓은 화면은 상품 4개를 보여주고 작은 화면에서는 카드 최소 폭을 확보해 가로 스크롤한다. 글자를 축소하거나 미리보기를 찌그러뜨리지 않는다. 기존 가로 스크롤을 유지할 경우 원본의 페이지 점·다음 화살표는 생략한다. 실제 페이지 이동을 구현하지 않고 장식용 페이지 버튼을 표시하지 않는다.

## 정적 이미지와 실제 UI 구분
정적 장식: 천 질감, 나무 틀, 구석 꽃·화분. 텍스트·아이콘이 붙은 화면 전체를 배경으로 깔지 않는다.

실제 UI: 제목, 설명, 탭, 잔액, 가격, 소유 상태, 버튼, 탐색 표시. Android UI로 렌더링하고 큰 글자·터치 영역·접근성 이름을 지원한다.

상품 미리보기: 저장소의 실제 캐릭터 스프라이트와 고향 배경을 재사용한다. 승인 시안의 생성 캐릭터를 잘라서 새 캐릭터로 쓰지 않는다. 별·물방울·하트는 실제 보유한 꾸미기 효과와 일치시킨다. 원본의 배경과 캐릭터 비율을 참고하되 현재 데이터에 없는 효과를 판매하지 않는다.

## 구매 상태
| 데이터 상태 | 표시 | 버튼 |
|---|---|---|
| 미보유·구매 가능 | 실제 가격 | 사기 |
| 미보유·잔액 부족 | 실제 가격·부족액 | N코인 부족, 비활성 |
| 보유·미사용 | 보유 | 쓰기 |
| 보유·사용 중 | 보유·초록 테두리 | 쓰는 중, 비활성 |
| 무료 기본 | 무료·보유 | 쓰기 또는 쓰는 중 |
| 로딩·저장 요청 중 | 불러오는 중 또는 처리 중 | 중복 요청 방지 |
| 조회 실패 | 다시 불러오기 안내 | 성공·보유로 오인시키지 않음 |

시안의 반짝 별은 이미 보유한 예시이므로 잔액 21코인에서도 ‘쓰는 중’이다. 부족액 19·29코인은 예시 잔액에서 계산한 값이며 실제 데이터로 계산해야 한다.

## 다른 탭에 확장할 기준 — 별도 승인 시안은 아님
| 탭 | 카드 내용 | 유의사항 |
|---|---|---|
| 음악 | 실제 친구·곡 제목·미리 듣기·가격·보유 | 재생과 구매 동작을 구분 |
| 물품 | 확정 물품 그림·친구 이름·보유 수량·단가 | 실제 소모품 구매 규칙 유지; 꾸미기의 ‘쓰기’를 복제하지 않음 |
| 코인 충전 | 코인 묶음·가격·충전 동작 | 기존 과제용 시연·실제 결제 아님 안내 유지; 실제 결제 도입 금지 |

## 개발 담당에게 남기는 작업
UI 재구성, 필요 장식 자산 분리, 실시간 데이터·기존 구매 로직 연결, 화면 크기 대응, 기능 검증은 개발팀 범위다. 디자인 담당의 완료 기준에 APK 빌드나 플레이 검증을 포함하지 않는다. 게임 물리·저장 스키마·음악·경제 수치를 디자인 적용 때문에 변경하지 않는다.
