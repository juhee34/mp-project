# 배경 그림 크기 안내 (B → A, 2026-11-12)

배경을 새로 그리거나 다시 맞출 때 쓰는 실제 크기입니다. 숫자는 앱에 들어 있는 파일과 코드에서 직접 잰 값입니다.

## 1. 달리기 배경 (게임 화면)

파일: `app/src/main/assets/backgrounds/running/<id>-intro.png`(집에서 출발하는 첫 장면) + `<id>-loop.png`(그 뒤 계속 이어지는 길). 목록과 바닥 높이는 `assets/backgrounds/manifest.json`.

| 친구 | intro (가로×세로) | loop (가로×세로) |
|---|---|---|
| 라일 mint | 1997×280 | 1440×280 |
| 치즈 cheese | 1564×280 | 1139×280 |
| 포포 popo | 1588×280 | 941×280 |
| 루미 lumi | 1682×280 | 1145×280 |
| 누누 nunu | 1713×280 | 982×280 |
| 피코 piko | 1682×280 | 1236×280 |

- **세로는 모두 280px, 바닥선(캐릭터 발이 닿는 줄)은 위에서 256px**(`floorY: 256`). 그 아래 24px는 땅입니다.
- 가로는 자유입니다. intro 다음에 loop가 끝없이 반복되므로 **loop의 왼쪽 끝과 오른쪽 끝이 이어져야** 합니다.
- 앱은 바닥선 위 256px를 화면 높이에 맞춰 키웁니다(픽셀을 흐리지 않고 확대).
  - 20:9 폰(2400×1080, 시연 에뮬레이터): 약 **3.66배** 확대. 한 화면에 보이는 그림은 가로 **약 656px × 세로 256px**(바닥선 위)입니다.
  - 16:9 폰(1920×1080): 같은 3.66배, 한 화면에 가로 **약 525px**입니다.
  - 바닥선 아래 24px는 화면 아래 땅 띠(약 144px)를 채우도록 늘어납니다. 땅은 단순한 무늬가 좋습니다.
- 화면 위쪽 띠(80dp, 시연 에뮬레이터에서 210px = 그림 기준 위에서 약 57px)에는 점수판(이름·거리·아이템·코인)과 정지/진행 버튼이 반투명하게 겹칩니다. 중요한 그림은 그보다 아래에 두세요.
- 캐릭터는 화면 왼쪽에서 약 15% 지점(에뮬레이터 360px)의 바닥선 위를 달리고, 그림 기준으로 키 약 69px만큼을 가립니다. 장애물은 바닥선 위 그림 기준 약 140px 높이까지(높은 상자 탑 기준, 공중 가시 막대는 약 120px까지), 아이템은 바닥 바로 위 또는 바닥선 위 약 65px 높이에 나옵니다.
- **더 선명하게 하고 싶으면 2배(세로 560, 바닥선 512)**로 그려도 됩니다. 그때는 manifest의 `rect` 높이와 `floorY`만 같이 바꿔 주세요. 앱 코드는 이 값으로 배율을 계산하고, 검사 스크립트의 원본 해시는 B가 함께 갱신합니다.

## 2. 화면 배경 (메뉴·로그인·이야기 모음 등)

| 쓰는 곳 | 파일 | 크기 |
|---|---|---|
| 기준 캔버스(시안·부품 좌표) | layout.json | **1672×941** (16:9) |
| 메인 메뉴 | `res/drawable-nodpi/bg_main_menu_wide.jpg` | **2091×941** (가운데 1672px가 시안) |
| 오프닝·로그인 | `bg_login_wide.jpg` | 2091×941 |
| 이야기 모음 | `bg_story_collection_wide.jpg` | 2091×941 |
| 마을 이야기·캐릭터 선택·내 기록 | `bg_common_paper_wide.jpg` | 2091×941 |

- 앱은 941px 높이를 화면 높이에 맞춥니다. 시연 에뮬레이터(2400×1080)에서는 **1.148배**, 양옆으로 그림 가로 약 2091px가 딱 화면 폭입니다.
- 16:9 폰(1920×1080)에서는 가운데 1672px만 보이고 양옆은 잘립니다. 그래서 **버튼·글자·캐릭터는 가운데 1672px 안**에, 양옆 210px씩은 이어지는 풍경만 두세요.
- 20:9보다 더 긴 화면은 양옆이 종이색으로 채워집니다.

## 3. 새로 그릴 때 권장 크기 (깨지지 않게)

기준 폰: 요즘 폰 대부분과 시연 에뮬레이터는 **세로 1080px**(가로 2340~2400px, 20:9)입니다. 그림을 이 높이에 **1:1로 맞추면** 확대가 없어 흐리거나 깨지지 않습니다.

### 달리기 배경

| 항목 | 권장 |
|---|---|
| 세로 | **1080px** |
| 바닥선(floorY) | **위에서 936px** (그 아래 144px가 땅) |
| intro 가로 | **2520~5000px** (첫 화면이 2520px 이상이어야 21:9 폰에서도 집이 꽉 참) |
| loop 가로 | **2520~4000px**, 왼쪽 끝과 오른쪽 끝이 이어지게 |
| 파일 | PNG 또는 WebP, 친구당 intro·loop 2장 |

- 이유: 게임은 화면 세로의 86.7%(1080폰에서 936px)를 바닥선 위 그림으로, 나머지 13.3%(144px)를 땅으로 씁니다. 바닥선 936·전체 1080으로 그리면 1080 폰에서 정확히 1배입니다.
- 1440px 폰(일부 고급 폰)에서는 1.33배로 조금 부드러워지지만 깨지지는 않습니다. 더 크게(1440) 그리면 메모리를 많이 써서 권하지 않습니다. 한 장이 5000px을 넘지 않게 해 주세요(가로 5000×1080 한 장이 메모리 약 21MB).
- **도트(픽셀) 느낌을 살리고 싶으면** 세로 **270px, 바닥선 234px**로 그리면 1080 폰에서 정확히 4배라 도트가 고르게 커집니다(지금 280/256은 3.66배라 도트 크기가 3~4칸으로 들쭉날쭉). 이때 intro는 630~1250px, loop는 630~1000px.
- 점수판은 화면 위 210px(1080 기준), 캐릭터는 바닥선 위 약 250px, 장애물은 바닥선 위 약 510px 높이까지 가립니다(1:1 크기 기준).
- 그림을 받으면 B가 manifest의 rect·floorY와 검사 해시를 바꿉니다. 코드는 그대로 둡니다.

### 화면 배경(메뉴·로그인·이야기 모음·마을 이야기)

| 항목 | 권장 |
|---|---|
| 크기 | **2400×1080** (지금 2091×941과 같은 비율, 1.148배) |
| 꼭 보여야 하는 부분 | **가운데 1920×1080** (16:9 폰은 여기까지만 보임) |
| 양옆 240px씩 | 이어지는 풍경·종이색만 (21:9 폰은 더 넓어 양옆이 종이색으로 채워짐) |

- 버튼·카드 부품도 같은 1.148배로 키워 주면 선명해집니다. 앱은 지금처럼 1672×941 기준 좌표(layout.json)를 그대로 쓰고 그림만 크게 그리므로, 좌표는 바꾸지 않아도 됩니다.
