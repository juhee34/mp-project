# 장애물 소품 콘셉트 1차

## 포포·루미 후속 시안

`popo-lumi.png`: 2행 3열 콘셉트 이미지. 위 행은 포포의 눈 덮인 바위·조개 바구니·장갑을 올린 보급 상자, 아래 행은 루미의 이끼 그루터기·솔방울 바구니·악기 상자다. 겨울 항구의 수집 생활과 가을 숲의 공연 준비를 표현한다.

최종 게임 자산은 아니다. 외곽 잔상/알파, 개별 PNG 분리, 픽셀 크기·바닥선·충돌 범위 검증이 남아 있다. 생성 시 투명 배경을 요청했으나 출력의 실제 알파 품질은 아직 검증하지 않았다. 게임 코드 변경 없음. 업로드는 사용자가 별도 Codex에 맡기기로 했다.

`mint-cheese.png`: 라일·치즈 각 3종, 2행 3열 시안. 게임용 최종 스프라이트가 아니다.

| 행 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 라일 | 고사리 통나무 | 파란 표식이 달린 이끼 바위 | 지도를 둔 보급 상자 |
| 치즈 | 작은 화분 | 묶은 노랑·초록 방석 | 닫힌 햇빛 틴 |

생활 소품으로 고향 이야기를 잇는다. 현재 시안에는 부드러운 외곽 광택/배경 잔상이 보여 배경과 합성하기 전 정리가 필요하다. 픽셀 크기, 최종 개별 PNG 분리, 바닥 기준선 및 투명 여백은 미확정이다. 장식 가지와 잎까지 충돌 영역으로 삼는다는 뜻이 아니다. B의 물리·게임 연결은 변경하지 않았다.

현재 파일은 1536×1024 시트 2장으로, 라일·치즈·포포·루미 4명 각 3종의 콘셉트 12종이다. 다음: 외곽 잔상 제거와 게임용 크기 정리, 개별 PNG 분리·바닥선·충돌 범위 검수, 누누·피코 소품 제작. 이전 게시 시도는 Git 쓰기 권한 오류로 실패했으며 이번 게시에도 최종 스프라이트가 아닌 콘셉트 상태를 유지한다.
