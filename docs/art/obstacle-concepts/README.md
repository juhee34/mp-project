# 장애물 소품 콘셉트 1차

**최신 납품:** [개발 인계](../OBSTACLE_HANDOFF.md). 18종 정리본은 `../obstacles/png/`에 있다. 이 폴더의 이미지는 원본 콘셉트 기록이며 실제 앱 연결에는 정리본을 사용한다.

이전 콘셉트 단계: [18종 검수 결과](REVIEW.md). 배경 합성 및 알파 표본 검사를 기록했다. 아래의 미검증 설명은 콘셉트 제작 당시 상태다. 이후 개별 PNG 18종의 아트 납품은 완료했으며 최신 규격과 게임 연결 미완료 항목은 위 개발 인계를 따른다.

## 누누·피코 후속 시안

`nunu-piko.png`: 2행 3열 콘셉트. 위 행은 누누의 책 묶음·반납 상자·책과 편지 바구니, 아래 행은 피코의 종이 보급 상자·밧줄 실패·종이배 공구함이다. 책을 나누는 생활과 종이배 제작 준비를 표현한다.

6명 각 3종, 총 18종 콘셉트 제작 완료. 최종 게임 자산 완료를 뜻하지 않는다. 모든 시트의 외곽 잔상/알파·개별 분리·픽셀 크기·바닥선 검수가 남아 있다. 누누 바구니 손잡이와 피코 종이배 돌출부는 충돌 형태 확정 전 검토 대상이다. Git 업로드는 별도 Codex 인계 범위이며 이번 대화에서는 실행하지 않았다.

## 포포·루미 후속 시안

`popo-lumi.png`: 2행 3열 콘셉트 이미지. 위 행은 포포의 눈 덮인 바위·조개 바구니·장갑을 올린 보급 상자, 아래 행은 루미의 이끼 그루터기·솔방울 바구니·악기 상자다. 겨울 항구의 수집 생활과 가을 숲의 공연 준비를 표현한다.

최종 게임 자산은 아니다. 외곽 잔상/알파, 개별 PNG 분리, 픽셀 크기·바닥선·충돌 범위 검증이 남아 있다. 생성 시 투명 배경을 요청했으나 출력의 실제 알파 품질은 아직 검증하지 않았다. 게임 코드 변경 없음. 업로드는 사용자가 별도 Codex에 맡기기로 했다.

`mint-cheese.png`: 라일·치즈 각 3종, 2행 3열 시안. 게임용 최종 스프라이트가 아니다.

| 행 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 라일 | 고사리 통나무 | 파란 표식이 달린 이끼 바위 | 지도를 둔 보급 상자 |
| 치즈 | 작은 화분 | 묶은 노랑·초록 방석 | 닫힌 햇빛 틴 |

생활 소품으로 고향 이야기를 잇는다. 현재 시안에는 부드러운 외곽 광택/배경 잔상이 보여 배경과 합성하기 전 정리가 필요하다. 픽셀 크기, 최종 개별 PNG 분리, 바닥 기준선 및 투명 여백은 미확정이다. 장식 가지와 잎까지 충돌 영역으로 삼는다는 뜻이 아니다. B의 물리·게임 연결은 변경하지 않았다.

첫 게시 당시에는 1536×1024 시트 2장, 4명 12종이었다. 현재 이 폴더에는 누누·피코를 포함한 시트 3장, 6명 18종의 이전 콘셉트를 보존한다. 최종 정리 PNG는 별도 `../obstacles/png/`에 있으며 이 폴더의 시트를 앱 자산으로 사용하지 않는다.
