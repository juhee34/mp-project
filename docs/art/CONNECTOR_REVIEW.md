# 최신 보정 상태 — 2026-11-10

연결 PNG 3장을 이미지 편집 도구로 보정했다. 아래 비교판과 기존 지적은 보정 전 기록이다. 새 비교판 실행은 PowerShell 실행 정책에 막혔으므로 최종 접합 검수 완료를 의미하지 않는다.

- 치즈: 왼쪽 중복 화분 제거. 루미: 왼쪽 큰 나무 제거.
- 피코: 추가 태양·왼쪽 말뚝 제거, 오른쪽 수국 축소와 돌출 단차 제거. 생성 중 생긴 중복 집은 재수정하여 제거.
- 라일·포포·누누: 경계 보정 생성본 확보. 수풀·바위·줄눈의 정확한 연결은 여전히 미완료다.
- 중앙 소품 구성은 유지하도록 편집했다. 픽셀 단위 중앙 원본 보존은 보장되지 않는다.
- loopReady=false 유지. 앱 자산 및 게임 코드는 변경하지 않았다.
- 이전 Git stage 시도는 .git/index.lock Permission denied로 실패했다. 이번 게시 검토에서는 현재 PNG의 치수·SHA-256과 manifest의 일치를 확인했다. 접합 완성 판정은 여전히 보류한다.

# 연결 배경 접합부 검수

## 보정 전 판정
6명 / 12개 접합부 모두 아트 경계 보정이 필요하다. 컨셉 승인과 무봉제 타일 완성은 구분한다. 이번 파일은 디자인 검수용이며 게임 적용 완료 자산으로 넘기지 않는다.

## 방법
보정 전 연결 PNG 3장으로 만든 비교판의 방법이다. 기존 원본의 각 캐릭터 영역과 당시 연결 시안의 영역을 나눠, 외곽 크림색 테두리를 제외한 양끝 230px씩을 1:1로 맞붙였다. 비교판은 각 영역 아래쪽 200px를 하단 기준으로 정렬했다. 확대·리샘플링·색 보정·블렌딩을 하지 않았으며 비교판 제작 시 원본 픽셀은 수정하지 않았다. 현재 manifest의 SHA-256은 이후 부분 보정된 PNG를 가리키므로 이 비교판의 입력 해시로 사용하면 안 된다. 전체 높이 및 상단 하늘 경계까지 통과했다는 의미는 아니다.

[12곳 접합부 비교판](review/connector-seams.png)

왼쪽 열은 원본 끝 → 연결 시작, 오른쪽 열은 연결 끝 → 원본 시작이다. 행 순서는 라일, 치즈, 포포, 루미, 누누, 피코.

| 캐릭터 | 원본 → 연결 | 연결 → 원본 |
|---|---|---|
| 라일 | 물가 뒤 언덕과 수풀 윤곽이 수직으로 끊김. | 뿌리 굵기·진행 방향과 나무껍질 명암이 불일치. |
| 치즈 | 연달아 나오는 화분의 반복감, 담장 명암·바닥 줄눈 불일치. | 벽 하단 경계가 단차처럼 보이며 벽돌 원근선이 끊김. |
| 포포 | 바위 덩어리와 가지 형태가 접합부에서 잘림. | 눈더미 경사와 바위·꽃 배치, 벽돌 줄눈 불일치. |
| 루미 | 수풀 명암과 나무뿌리 덩어리가 수직으로 바뀜. | 큰 뿌리 단면과 식생이 이어지지 않음. |
| 누누 | 안개·수풀 색면 및 바위 실루엣, 벽돌 줄눈 불일치. | 수풀·바위 밝기와 크기 차이, 포장면 경계가 끊김. |
| 피코 | 운하 물색·반사 무늬와 목재 기둥 배치가 불연속. | 수국 크기와 잎 밀도가 다르고 벽돌·나무 데크가 끊김. |

## 다음 아트 보정 범위
- 가운데의 승인된 생활 소품과 구도는 유지한다. 전체 재생성으로 다시 디자인하지 않는다.
- 양끝 약 200~300px 구간을 원본의 실제 접합 픽셀에 맞춰 수정한다. 바닥선뿐 아니라 벽돌 줄눈·수면·나무뿌리·수풀 덩어리를 이어야 한다.
- 보정 후 동일한 비교판을 다시 생성해 12곳을 확인한다. 이미지 생성만 끝났다는 이유로 loopReady를 true로 바꾸지 않는다.
- 현재 소스 크기가 다름: 원본 3장 2169×725, 연결 라일/치즈·누누/피코 2172×724, 연결 포포/루미 2169×725. 전체 시트를 일괄 확대하거나 단순 반분하지 않는다. manifest의 영역은 보정 전 비교용이며 최신 이미지에 재검증되지 않은 좌표다. 게임 적용 좌표 확정이 아니다.
- 담당 범위는 A팀 아트 원본·접합 검수·수정이다. B팀 게임 코드·충돌·렌더링은 이번 작업에서 변경하지 않았다.
