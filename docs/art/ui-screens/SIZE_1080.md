# 화면 그림 크기 기준 (2026-11-12, A)

게임(달리기) 화면을 뺀 모든 화면 그림은 **세로 1080px, 20:9(2400×1080)** 기준으로 맞췄습니다. 에뮬레이터와 요즘 폰 대부분이 세로 1080px라 1배로 그려져 늘어나지 않습니다.

| 파일 (`res/drawable-nodpi`) | 이전 | 지금 |
|---|---|---|
| bg_main_menu_wide.jpg / bg_login_wide.jpg / bg_common_paper_wide.jpg | 2091×941 | **2400×1080** |
| login_card.png, ui_login_*, ui_menu_btn_* | 941 기준 | ×1.148 (1080 기준) |

- 코드 변경 없음. `MockupFrame`·`PaperBackdropView`는 그림의 가로세로 비율만 쓰므로 그대로 맞습니다. 좌표(layout.json, HubActivity의 rect)는 계속 **1672×941 기준 px**입니다(가운데 1672×941 = 2400×1080의 가운데 1919×1080).
- 원본 시안이 1672×941이라 크기를 키워도 새 디테일이 생기지는 않습니다. 시안을 1080 높이로 다시 받으면 같은 이름으로 바꾸면 됩니다.
- `docs/art/ui-screens/backgrounds/bg_login_scene_*.png`: 로그인 시안에서 카드·친구들을 뺀 배경만(가운데 카드 자리는 보정). 앱에는 아직 연결하지 않음.

## B 추가 (2026-11-12)
- 남은 화면 배경 2종도 2400×1080으로 맞춤.
  - `bg_opening_wide.jpg`: A의 `bg_login_scene_2400x1080.png`(카드 없는 들판) 위에 1080 로그인 배경의 친구 6명을 그대로 옮김. 예전 보정 이음새가 사라짐.
  - `bg_story_collection_wide.jpg`: 2091×941을 1080/941배로 키움(새 디테일 없음).
- 이제 게임 화면 외 배경 5종이 모두 2400×1080.
- 메인 메뉴(2026-11-13, B): 시안의 친구 6명을 배경에서 지우고(풀밭 색으로 채움) 앱에서 게임 스프라이트로 간격을 넓혀 그림. 책 바깥(20:9로 늘리며 번진 부분)은 6px 도트 나무 책상(가로 판자·결·이음매·책 그림자)으로 새로 그림. 책 윤곽·위의 책 두 묶음·책갈피는 그대로.
- 움직이는 구름(2026-11-13, B): 오프닝·메인 메뉴 배경에서 구름을 떼어 `ui_clouds_opening.png`(2400×470)·`ui_clouds_main_menu.png`(2400×560)로, 하늘 자리만 흰색인 `ui_sky_*.png`를 함께 만듦. 앱(`ui/CloudDrift`)이 구름 층을 초당 14px로 흘리고 하늘 자리에서만 보이게 해 나무·제목·언덕·책 가장자리 뒤로 지나감. 배경을 새로 받으면 구름도 다시 떼어야 함.
