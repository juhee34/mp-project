# 메인 메뉴 최종본 + 캐릭터 통일 (A 확정, 2026-11-12)

## 1. 메인 메뉴 (HubActivity)

A가 확정한 그림책 메뉴 시안을 그대로 쓰도록 나눴습니다. 기준 캔버스는 지금과 같은 1672×941(`MockupFrame`)입니다.

| 파일 | 내용 |
|---|---|
| `res/drawable-nodpi/bg_main_menu_wide.jpg` | 새 배경 2091×941. 가운데 1672px가 시안(버튼·글자만 지움), 양옆은 책상 색을 이어 붙임 |
| `res/drawable-nodpi/ui_menu_btn_primary.png` | 진초록 버튼(스토리 진행하기), 글자 없음 |
| `res/drawable-nodpi/ui_menu_btn_secondary.png` | 크림색 테두리 버튼(나머지 4개), 글자 없음 |
| `docs/art/ui-screens/main-menu-final/layout_main_menu.json` | 버튼 좌표·글자·색·크기 |

버튼 좌표(기준 px): 스토리 진행하기 610,317–1061,401 / 게임하기 619,410–1053,488 / 상점 618,497–1053,575 / 튜토리얼 619,584–1053,663 / 설정 619,672–1053,750.
`HubActivity`는 이 좌표로만 바꿨고 동작(버튼이 여는 화면)은 그대로입니다.

제목·부제·여섯 친구·나무는 배경 그림에 들어 있습니다. 친구들은 확정 시안의 그림 그대로입니다.

## 2. 캐릭터는 게임 스프라이트로 통일

- 게임 안에서 캐릭터를 그리는 화면(선택·프로필·달리기·결과·가방·상점·대화·이야기 목록/모음·오프닝 대체 그림)은 모두 `CharacterSprites` → `sprite_<id>_*.png`를 씁니다. 이 PR은 그 스프라이트를 A 확정본으로 바꿉니다:
  라일은 원본(옆모습, 눈 하나), 치즈·포포·루미·누누·피코는 두 눈 크기를 맞춘 버전(PR #8 내용).
- 오프닝·로그인 배경 `bg_login_wide.jpg`에 그려져 있던 시안 캐릭터 여섯 명을 같은 스프라이트(4배, 흐림 없음)로 바꿨습니다.
- 이 PR은 PR #8(`codex/ui-screens-handoff`)을 포함합니다. 이 PR을 병합하면 #8은 닫아도 됩니다.
