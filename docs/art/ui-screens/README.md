# UI 화면 3종 — 배경/부품 분리본 (A 납품)

승인 시안 3장(메인 메뉴, 로그인, 이야기 모음)을 앱에 그대로 올릴 수 있게 **배경 그림**과 **누르거나 바뀌는 부품**으로 나눈 자료입니다.
캐릭터 6명, 제목(Tiny Runners / 이야기 모음), 나무·집·벤치 같은 장식은 배경에 남겼습니다. 글자는 모두 지웠으니 앱 코드에서 문자열로 그립니다.

상태: `art_ready_for_integration`, `integrated=false` — 앱 코드 연결과 기기 확인은 아직입니다.

## 폴더

| `approved/` | 원본 시안 3장 (1672×941) | 넣지 않음 (기준 자료) |

## 적용 방법 (권장: 시안 좌표 그대로)

모든 좌표는 **1672×941 기준 캔버스**의 픽셀입니다. 화면 크기에 맞춰 같은 배율로 키우면 시안과 똑같은 배치가 됩니다.

```kotlin
// 기준 캔버스 1672x941. 높이에 맞춰 키우고 가로 가운데 정렬 → 16:9~20:9 폰에서 부품이 잘리지 않음.
val scale = minOf(viewW / 1672f, viewH / 941f)
val offX = (viewW - 1672f * scale) / 2f
val offY = (viewH - 941f * scale) / 2f
fun place(v: View, x0: Int, y0: Int, x1: Int, y1: Int) {
    v.layoutParams = FrameLayout.LayoutParams(((x1 - x0) * scale).toInt(), ((y1 - y0) * scale).toInt())
    v.x = offX + x0 * scale; v.y = offY + y0 * scale
}
// 배경: bg_*_wide 를 높이 941*scale, 가로 가운데 정렬로 깔면 부품과 정확히 겹침 (wide 의 가운데 1672px = 원래 배경)
// 글자 크기: layout.json 의 text_size_px * scale 을 TypedValue.COMPLEX_UNIT_PX 로 지정
```

- 버튼은 `parts/` PNG를 `background`로 쓰고 글자는 `text`로 넣습니다.
- 버튼 크기를 시안과 다르게 바꿀 때만 `ninepatch/` 또는 `xml/`을 쓰세요.
- 20:9보다 더 길쭉한 화면은 `*_wide` 배경 양옆이 살짝 비고, 4:3 태블릿은 위아래 여백이 생깁니다(과제 시연 폰 기준으로는 문제 없음).
- `*_wide`의 늘린 양옆: 메인·이야기 모음은 종이색, 로그인은 풍경을 좌우 반전으로 이어 붙이고 반복된 캐릭터는 지웠습니다.

## 화면별 메모

**메인 메뉴** — 버튼 5개는 같은 위치에 겹쳐 놓는 기준으로 만들었습니다. 버튼 뒤 자리는 시안의 크림색 빛 번짐을 하나의 부드러운 판으로 채웠습니다.

**로그인** — 카드·제목·부제는 배경에 있습니다. 입력칸 2개는 같은 `ui_login_input`을 쓰고, 안쪽 여백은 좌우 26px입니다. 라벨(이메일/비밀번호)은 왼쪽 정렬 글자입니다.

**이야기 모음** — 카드 4장은 모두 부품입니다. 카드 틀(`ui_story_card_frame`) 위에 리본 → 제목 글자 → 썸네일 → (본 이야기 알약) → 버튼 순서로 올립니다. 카드 뒤 배경은 무늬 없는 종이색과 벤치로 채웠습니다(카드가 덮는 자리). 상단 왼쪽 뒤로가기는 화살표만 남기고 글자를 지웠습니다.

## 한계 (사실대로)

- 시안 해상도가 1672×941이라 큰 화면에서는 살짝 부드럽게 확대됩니다. 더 선명한 원본이 생기면 같은 이름으로 교체하면 됩니다.
- 버튼·카드 뒤에 가려져 있던 배경은 원래 그림이 없어서 **보정으로 채웠습니다**. 부품을 원래 자리에 올리면 안 보이지만, 부품을 빼거나 옮기면 보정한 자리가 드러납니다.
- 이야기 모음 썸네일과 리본은 시안에 있는 **세계·라일·치즈·포포 4개뿐**입니다. 루미·누누·피코 카드용 그림과 리본은 아직 없습니다.
- `preview/`의 글꼴은 확인용 Noto Sans입니다. 시안의 둥근 글꼴은 앱에서 정해야 합니다.
- 글자 크기·색은 시안에서 잰 근삿값입니다.
