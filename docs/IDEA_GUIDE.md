### 1-2. "길게 누르기" 대신 스킬 버튼을 권한다
- 지금은 손가락을 대는 순간 점프한다. 길게 누르기로 스킬을 쓰면 **누르는 순간 이미 점프가 나가거나**, 점프를 0.3초쯤 늦춰야 한다. 둘 다 조작감이 나빠진다.
- 대안: 화면 오른쪽 아래에 **스킬 버튼**(쿨타임이 원으로 차오름)을 둔다. 점프는 화면 아무 곳이나 탭한다. 시연할 때도 설명하기 쉽다.
- 팀이 길게 누르기를 원하면: 0.4초 이상 누르면 스킬, 그 전에 떼면 점프로 판정한다. 이때 점프가 0.4초 늦어지는 것을 받아들여야 한다.

## 2. 아이디어 B: 스토리 진행

### 2-1. 구조 제안
- **주인공 = 플레이어.** 그림 없이 대사만 나온다. 이름은 **회원가입 닉네임**을 쓴다(로그인 요건과 자연스럽게 연결된다). 임시 모드면 "나그네".
- 주인공이 마을을 돌며 6명을 만난다. 각 친구의 "작은 바람"(stories.json의 `*_intro`, characters.json의 `centralConflict`)이 출발점이다.
- **이야기 → 함께 달리기 → 이야기 마무리** 순서다. 달리기는 그 친구로 플레이한다(팀 메모의 "게임은 마을주민으로").
- 달리기의 목적은 이기기가 아니라 **함께 다녀오기**다. 부딪혀서 끝나도 이야기는 이어진다(실패 벌칙 없음).

### 2-2. "문제 해결"을 쓰는 방법
지금 개요는 이미 "고쳐 주기"가 아니라 "다른 방식으로 함께하기"로 끝난다. 이 방향을 유지한다.

| 캐릭터 | 지금 개요의 끝 | 달리기와 잇는 예 |
| --- | --- | --- |
| 라일 | 길 대신 냄새와 바람 소리를 지도에 그린다 | 함께 달리며 고사리 언덕의 바람 소리를 모은다 |
| 치즈 | 빈 통에 담긴 마음을 친구가 알아본다 | 햇볕 지붕마을을 달려 누누에게 통을 전한다 |
| 피코 | 빠른 물길보다 친구들의 정박지를 잇는다 | 운하를 따라 정박지를 하나씩 들른다 |

### 2-3. 대사와 선택지
- 화면 탭으로 다음 대사, 위쪽에 **건너뛰기** 버튼.
- 선택지는 에피소드당 **최대 1~2개**, 바로 다음 대사만 달라진다. 결말이 갈라지지 않는다(작성량 폭발 방지).
- 정답·오답 선택지를 만들지 않는다. 고른 말에 따라 친구의 반응 말투만 다르다.

### 2-4. 데이터 형식 제안(확정 시 DATA_CONTRACT.md와 검사기 갱신)
`stories.json`의 각 이야기에 `lines`를 더한다. 기존 `body`(개요)는 도감 요약으로 남긴다.
```json
{
  "id": "mint_intro", "characterId": "mint", "title": "라일의 작은 바람",
  "status": "draft", "unlock": { "afterStory": null },
  "lines": [
    { "speaker": "mint", "text": "이 길, 어제는 여기 없었는데…" },
    { "speaker": "player", "text": "지도를 또 고치는 거야?" },
    { "choice": [
        { "text": "같이 걸어 볼까?", "reply": [{ "speaker": "mint", "text": "정말? 그럼 바람 소리부터!" }] },
        { "text": "지도 말고 냄새를 그려 보자", "reply": [{ "speaker": "mint", "text": "냄새…? 그거 좋은데!" }] }
    ] },
    { "run": true },
    { "speaker": "mint", "text": "지도는 틀렸지만, 오늘은 길을 잃지 않았어." }
  ]
}
```
- `speaker`: 캐릭터 ID 또는 `player`(닉네임으로 표시).
- `{ "run": true }`: 여기서 그 친구로 한 판 달린다. 결과와 상관없이 다음 대사로 이어진다.
- 해금: 첫 이야기는 처음부터 열림. 다음 이야기는 앞 이야기를 본 뒤 열린다. 거리 조건을 쓰면 짧은 시연에서 확인할 수 있는 값으로만 쓴다.

## 4. 이 아이디어가 보고서·발표에 주는 점
- 차별화: "고르는 친구마다 다른 이야기와 스킬 연출, 같은 공정한 규칙".
- 시연 흐름(3~5분): 로그인 → 친구 선택 → 이야기 몇 줄과 선택지 → 함께 달리기(2단 점프·스킬) → 이야기 마무리 → 내 기록.

## 5. 하지 않을 것
- 캐릭터마다 다른 점프 높이·속도·스킬 위력.
- 이야기를 열기 위한 높은 점수 조건, 매일 접속 보상, 안 하면 줄어드는 호감도.
- 주인공 그림(팀 메모대로 대사만).
