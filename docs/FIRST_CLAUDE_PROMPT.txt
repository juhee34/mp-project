README.md, CLAUDE.md, PROJECT_STATE.md, docs/START_HERE.md, docs/DATA_CONTRACT.md를 읽고 이 프로젝트를 이어서 개발해줘.
나는 학교 과제로 Android Studio 앱을 만들고 있어. 첫 시연부터 10명 전원 선택과 플레이가 가능해야 해. 캐릭터를 한 명으로 줄이지 마.
우선 현재 코드와 개발 환경을 점검하고 JDK 17, Android SDK 35, Gradle Wrapper를 준비한 다음 실제 빌드와 실행을 확인해줘. 기존 코드의 컴파일 오류가 있으면 고쳐줘.
그 다음 10명 선택 화면을 유지하면서 공통 2D 러닝 게임을 구현해줘. 터치 점프, 장애물, 공정한 충돌, 거리/점수, 일시정지, 재시작이 필요해. 이미지와 음악은 아직 예정 상태이므로 임시 소재와 완성 소재를 구분해줘.
이번에는 기본 게임까지 끝내고 실제 검증 결과와 다음 작업을 보여줘. 배경 10장과 음악 10곡을 만들었다고 가정하지 마. 변경 파일과 PROJECT_STATE.md를 갱신해줘.
