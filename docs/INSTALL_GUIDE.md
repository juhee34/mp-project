# Tiny Runners 설치 안내

여섯 친구와 함께 달리는 작은 픽셀 러너입니다. 학교 과제용 시험 버전이라 플레이 스토어가 아니라 **APK 파일**로 설치합니다.

## 받는 사람: 설치 방법 (안드로이드 휴대폰)
1. 받은 파일 **`TinyRunners-v1.0.0.apk`**를 휴대폰에서 엽니다. (카카오톡이면 파일 → 저장 후 열기, 구글 드라이브면 다운로드 후 열기)
2. "이 출처의 앱 설치를 허용할까요?"가 나오면 **설정 → 이 출처 허용**을 켜고 뒤로 돌아와 **설치**를 누릅니다. 이 허용은 설치가 끝나면 다시 꺼도 됩니다.
3. "Play 프로텍트" 경고가 나오면 **무시하고 설치**(또는 세부정보 → 설치)를 누릅니다. 스토어에 등록되지 않은 학교 과제 앱이라 나오는 안내입니다.
4. 앱 목록의 **Tiny Runners**(보라색 공룡 아이콘)를 엽니다.
5. **시작하기 → 처음이라면 회원가입**에서 닉네임·이메일·비밀번호(6자 이상)를 정합니다. 다른 사이트에서 쓰는 비밀번호는 쓰지 마세요.
6. 친구를 골라 달리면 기록이 내 계정에 저장됩니다.

- 필요 환경: Android 8.0 이상, 인터넷 연결(로그인·기록 저장·날씨)
- 화면이 가로로 돌아갑니다. 처음 달릴 때 조작 안내가 나옵니다.
- 지울 때: 앱 아이콘 길게 누르기 → 제거. 계정 기록은 서버에 남아 다시 설치해도 이어집니다.

## 보내는 사람: 공유 방법
- 파일 위치: 프로젝트 폴더의 `dist/TinyRunners-v1.0.0.apk` (약 6.6MB). `dist/`는 Git에 올라가지 않습니다.
- 카카오톡·구글 드라이브·메일로 보내고, 아래 "같이 보낼 문구"를 붙여 넣습니다.
- 새 버전을 만들 때: `.\gradlew.bat :app:assembleDebug` 후 `app/build/outputs/apk/debug/app-debug.apk`를 `dist/TinyRunners-v<버전>.apk`로 복사합니다. 버전은 `app/build.gradle.kts`의 `versionName`/`versionCode`를 올립니다.
- **같은 PC에서 만든 APK끼리만 덮어쓰기 설치가 됩니다.** 이 파일은 그 PC의 디버그 키로 서명됩니다. 다른 팀원 PC에서 만든 APK로 바꾸려면 기존 앱을 지우고 설치해야 합니다(서버에 저장된 계정 기록은 그대로).
- APK에는 Firebase 연결 정보가 들어 있어 받는 사람은 설정 없이 회원가입·로그인할 수 있습니다. 각자 기록은 본인 계정에만 저장되고 다른 사람 기록은 볼 수 없습니다(Firestore 보안 규칙).

## 같이 보낼 문구 (복사용)
```
Tiny Runners 시험 버전이에요! 🏃
여섯 친구 중 한 명을 골라 함께 달리는 픽셀 러너 게임이에요.

[설치]
1. 첨부한 TinyRunners-v1.0.0.apk 파일을 휴대폰에서 열기
2. "이 출처 허용" 켜고 설치 (Play 프로텍트 경고가 나오면 '무시하고 설치')
3. 앱을 열고 시작하기 → 처음이라면 회원가입
   (비밀번호는 다른 곳에서 안 쓰는 새 비밀번호로!)

안드로이드 8.0 이상, 인터넷 연결 필요해요.
화면을 누르면 점프, 높은 탑은 공중에서 한 번 더 눌러 2단 점프예요.
```

## 이 파일은 정식 출시본이 아닙니다
- 디버그 키로 서명된 시험용 APK입니다. 플레이 스토어 출시는 이번 과제 범위 밖이며, 출시한다면 별도 서명 키와 Google Play 개발자 계정(예산표 항목)이 필요합니다.
