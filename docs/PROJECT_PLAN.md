# Tiny Runners — 6명 캐릭터 기획서

작성일: 2026-11-09 · A 역할 기획 · 저장소: mp-project

## 확정 범위와 목표

Android Studio를 사용하는 학교 과제용 2D 러너다. 간단한 점프로 친구의 고향을 달리고, 함께한 시간이 쌓일수록 이야기를 알아간다. 높은 점수 외에도 “이 친구와 조금 더 함께하고 싶다”는 마음이 재방문의 이유가 되도록 한다.

**첫 플레이 가능한 시연부터 민트·치즈·포포·루미·누누·피코 6명 전원 선택과 실제 플레이가 가능해야 한다.** 프로필만 6개인 것은 완료가 아니다. 어느 친구든 시작 → 점프 → 충돌 → 결과 → 재시작이 동작해야 한다. 모찌·볼트·밤이·솔은 이번 범위에서 제외한다.

기본 속도·점프·충돌 판정은 동일하고 외형·동작·고향·음악·이야기로 개성을 표현한다. 뽑기, 결제, 연속 접속 강요, 미접속 친밀도 감소는 넣지 않는다. 이 문서는 기획이며 실제 구현 완료를 의미하지 않는다.

## 조사 근거와 차별화 방향

기존 research/의 이야기 연구 205건(이솝 40, 안데르센 40, 그림 40, 현대 작품 40, 세계 이야기 45)과 유사 게임 10건을 활용한다. 원문 또는 실질적인 소개·시놉시스를 검토한 자료이며, 205편 전편 완독·시청이나 비교 게임 전체 직접 플레이를 의미하지 않는다. 출처 URL과 검토 범위는 각 JSON에 보존한다.

| 연구 원리 | 적용 |
| --- | --- |
| 소품에 남는 기억이 애착을 만든다 | 지도·빈 통·조개 상자가 에피소드마다 다른 의미를 얻는다 |
| 원하는 결과와 다른 따뜻한 결말도 가능하다 | 목표 달성만이 아니라 함께 발견한 것과 달라진 관계를 보여준다 |
| 말과 행동 사이의 작은 차이가 인물을 기억하게 한다 | 태연한 치즈의 기대가 꼬리 끝에 드러난다 |
| 귀환은 실패가 아닌 안도감이 될 수 있다 | 실패 뒤 고향에서 쉬는 연출을 둔다 |
| 서로 다른 속도를 인정하며 공감을 만든다 | 피코와 포포가 서로를 고치려 하지 않고 함께하는 방법을 찾는다 |

움직이는 고사리 길, 담기지 않는 햇빛, 사라지는 발자국 같은 판타지 사건으로 호기심·서운함·질투·안도를 표현한다. 현실의 성적·취업·경제 문제나 죽음의 사연을 직접 가져오지 않는다. 원작의 사건·대사·상징을 그대로 복제하지 않는다.

Dashimals의 귀여운 원터치 러너, Summer Catchers의 픽셀 여행과 이야기, CookieRun의 다수 캐릭터와 스토리, Alto의 풍경·음악·차분한 플레이 등과 겹치는 요소가 있다. 캐릭터별 음악과 공룡 러너의 스킨 변경도 기존 사례가 있어 각각을 최초 기능이라고 주장하지 않는다. 공식 소개에서 확인하지 못한 기능을 “없다”고 단정하지 않는다.

우리의 차별화 목표는 **동일 성능의 6명 + 각자의 고향 + 서로 연결되는 이야기 + 실패해도 남는 동행 기록**의 결합이다. 시장 유일성이 검증됐다는 의미는 아니다.

## 캐릭터 목록과 선택 순서

| ID / 이름 | 모습·사는 곳 | 성격 | 이야기 중심 |
| --- | --- | --- | --- |
| mint / 민트 | 민트색 공룡 · 고사리 언덕의 뿌리집 | 호기심이 많고 안내를 좋아하지만 방향 감각은 느긋하다 | 움직이는 길을 정확히 그리려다 친구들과 기억을 담는 지도를 만든다 |
| cheese / 치즈 | 살구색 고양이 · 햇볕 지붕마을의 둥근 창문방 | 태연한 척하지만 선물 선택은 신중하다 | 누누에게 햇빛을 선물하려다 빈손으로 찾아오는 시간의 소중함을 경험한다 |
| popo / 포포 | 남색 펭귄 · 눈꽃 항구의 조개지붕집 | 조용히 관찰하고 좋아하는 것을 오래 간직한다 | 서로 다른 여름의 소리를 담아 익숙한 집으로 돌아온다 |
| lumi / 루미 | 황갈색 여우 · 호박빛 메아리 숲의 빈 나무집 | 장난과 말재주가 있지만 침묵은 어색하다 | 사라진 메아리를 찾으며 말없이 함께하는 시간을 발견한다 |
| nunu / 누누 | 민트 리본의 크림색 유령 · 안개 도서관의 책갈피방 | 소심하고 장난기가 있으며 놀라게 하기는 싫다 | 사라지지 않는 발자국 대신 친구들의 기억에 남은 흔적을 발견한다 |
| piko / 피코 | 우비를 입은 노란 오리 · 물방울 운하의 종이배 선착장 | 활발하고 친근하지만 급하면 설명을 생략한다 | 빠른 물길보다 함께 머물 정박지를 만드는 즐거움을 발견한다 |

관계 수정: 민트는 피코의 종이배 여행 지도를 그린다. 포포는 루미와 조용히 머무는 시간을 좋아한다. 치즈와 민트는 누누가 앉던 자리를 기억한다. 피코는 포포를 위한 정박지를 만든다. 제외된 네 캐릭터의 역할에 의존하지 않는다.

## 필수 기능과 단계별 완료 기준

| 기능 | 첫 플레이 시연 | 최종 목표 |
| --- | --- | --- |
| 선택 | 6명 모두 게임 진입 | 초상·선택 반응·프로필 |
| 러닝 | 자동 전진·점프·장애물·충돌·거리·재시작 | 난이도·일시정지·안정적인 복귀 |
| 캐릭터 표현 | 6명을 구별하는 임시 표현 허용 | 달리기·점프·착지·실패 동작 |
| 배경 | 임시 상태 명시 | 고향 배경 6종 |
| 음악 | 무음 또는 명확한 임시곡 | 전용 음악 6곡·음소거 |
| 이야기·도감 | 성격·집·이야기 개요 | 각자 완성 소개와 첫 에피소드, 후속 2개 개요 |
| 기록 | 한 판 거리·결과 | 캐릭터별 누적 거리·최고 기록·읽은 이야기 |

로그인·서버·멀티플레이·상점·온라인 순위는 필수 범위에 넣지 않는다. 일정이 촉박하면 후속 이야기와 연출의 양을 조정하며, 확정한 6명 전원 플레이 조건은 유지한다.

## 화면 흐름

**소개 → 캐릭터 선택 → 게임 → 결과 → 도감 또는 재시작**

| 화면 | 내용 | 이동 |
| --- | --- | --- |
| 소개 | 핵심 콘셉트·조작 안내·시작 버튼 | 선택 |
| 선택 | 6명 목록·이름·성격·고향·프로필 | 선택한 친구로 게임 |
| 게임 | 캐릭터·배경·거리·점프·일시정지 | 충돌 시 결과, 일시정지 후 계속 |
| 결과 | 이번 거리·반응·새 이야기 안내 | 같은 친구로 재시작, 다른 친구 선택, 도감 |
| 도감 | 프로필·열린 이야기·동행 기록 | 다시 읽기, 이전 결과 또는 선택으로 복귀 |

재시작은 선택 캐릭터를 유지한다. 캐릭터 변경 시 배경·음악·기록의 연결도 바뀐다. 이야기를 읽지 않아도 게임을 계속할 수 있다. 실패 거리도 동행 기록에 반영하는 방향을 제안하며 중복 누적을 막는다.

## B와 합의할 데이터 규격

| 필드 | 형태 | 규칙 |
| --- | --- | --- |
| characterId | 문자열 | mint, cheese, popo, lumi, nunu, piko 중 하나 |
| name | 문자열 | 표시 이름, ID와 분리 |
| personality | 문자열 | 프로필·대사에 사용하는 성격 |
| home | 문자열 | 고향·집 표시 이름 |
| portraitPath | 문자열 또는 null | 초상 이미지, 미제작은 null |
| spritePath | 문자열 또는 null | 게임 동작 이미지, 규격 별도 합의 |
| backgroundId | 문자열 | 배경 목록 참조 |
| musicId | 문자열 | 음악 목록 참조 |
| storyIds | 문자열 배열 | 존재하는 이야기 ID만 참조 |

기존 JSON의 키 id는 유지한다. 화면·결과 전달값 characterId는 같은 값을 뜻하도록 제안하며, 키 이름의 전면 변경은 B와 합의 없이 하지 않는다. 미제작 파일 경로는 만들어내지 않는다.

결과는 RunResult(runId, characterId, distance, score), 진행도는 CharacterProgress(characterId, totalDistance, bestScore, readStoryIds)를 제안한다. runId로 중복 저장을 막는다. 스프라이트 셀 크기·프레임 수·발 기준선은 실제 러너에서 먼저 검증한다.

## 역할 분담

A(ChatGPT·Codex): 캐릭터·서사·이미지·배경·음악 방향, 소개·선택·프로필·도감 화면, 발표 자료.

B(Claude Code): 환경·러닝 엔진·충돌·점수·애니메이션 적용·오디오·저장·화면 통합·실기기 검사.

공동: 데이터 규격, 공통 파일 변경, 6명 전체 시연과 교차 검수. 작업 중인 다른 사람의 변경을 덮어쓰지 않는다.

## 검증 기준

6개 ID와 이름·순서·참조가 일치해야 한다. 각자 선택 → 게임 → 결과 → 재시작과 도감 복귀를 검증한다. 임시 자산과 완성 자산을 구분하고 실제 음원·그림·빌드가 없는데 완료했다고 쓰지 않는다. 기존 205건 조사 및 비교 게임 10건은 캐릭터 수 축소와 무관하게 유지한다.
