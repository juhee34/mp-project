# TINY RUNNERS 소개 웹사이트

Android 앱과 별도의 정적 소개·이야기 감상 사이트. 사용자 요청으로 추가했으며 학교 과제의 필수 웹사이트 요구를 의미하지 않는다.

## 구성
- dist/index.html, styles.css, app.js: 반응형 소개 화면, 여섯 친구 탭, 고향 배경, 이야기 읽기 창, 플레이 안내, 기능 상태, 역할·연구·발표 안내.
- dist/data.js: 현재 캐릭터 데이터와 ready 이야기 12개. outline 본문은 제외한다.
- dist/assets: 승인된 배경 manifest의 영역을 그대로 발췌한 PNG 6개 및 기존 스프라이트 6개. 원본 디자인 변경 없음.
- dist/TINY_RUNNERS_INTRO.md: 발표용 소개서 다운로드 사본.
- .openai/hosting.json: 전용 사이트 ID와 정적 배포 설정. 토큰/키 없음.

## 재생성·실행
Windows PowerShell에서 `./website/build-content.ps1` 실행. System.Drawing으로 배경 영역만 발췌하고 Python 표준 라이브러리로 현재 콘텐츠와 스프라이트를 복사한다. 원본 앱 파일은 수정하지 않는다. UTF-8 사용.

`python -m http.server 8765 --bind 127.0.0.1 --directory website/dist` 후 http://127.0.0.1:8765 에 접속한다. `node --check website/dist/app.js`로 JS 구문 확인.

웹사이트는 게임 엔진·계정·앱 저장에 연결되지 않는다. 소개서의 다운로드는 Markdown 파일이다. 음악 재생이나 APK 설치 버튼을 제공하지 않는다. 앱의 미구현 상태가 바뀌면 index.html 상태 안내와 발표 소개서를 갱신하고 data.js를 재생성한다.

사이트 전용 배포 저장소와 mp-project GitHub는 별개다. 사이트 배포가 성공해도 mp-project의 website/가 자동 커밋되지는 않는다. 본 프로젝트 게시 시 website/ 전체(생성된 dist 포함)와 관련 문서를 포함해 검토한다. 임시 배포 checkout이나 인증 정보는 포함하지 않는다.

## 검수
로컬 HTTP 200, JS 구문 검사, 데스크톱에서 실제 배경·화면 배치, 여섯 친구 선택과 각 첫 이야기 제목 일치, 이야기 창 열기·닫기, 배경 이야기 열기를 확인했다. 작은 화면용 CSS와 키보드 탭 이동을 구현했으나 모바일 실제 기기 검수는 별도다. 앱의 기기 검수 완료를 뜻하지 않는다.
